# 架构说明

## 目标与边界

Douyin TV 是一个原生 Android TV 客户端：短视频和直播画面由 Media3/ExoPlayer
播放，界面由 Jetpack Compose 构建。WebView 只用于抖音官方网页的扫码登录，
不承载推荐流、直播列表或视频播放。

项目依赖抖音网页端的公开请求与运行时可观察行为，因此它不是稳定协议客户端。
接口参数、签名、风控、登录页 DOM 和媒体地址变化都可能导致部分功能失效。

## 运行时结构

```text
MainActivity
  └─ DouyinTvApp
      ├─ ShortsScreen          Compose + PlayerView + ShortsPlaybackEngine
      │   ├─ DanmakuOverlay    五轨弹幕画布
      │   └─ CommentsPanel     右侧评论抽屉
      ├─ MyHomeSidebar         右侧账号主页：观看历史 / 收藏 / 本人作品
      ├─ AuthorProfileSidebar  右侧博主主页：视频 / 合集（无公开合集时隐藏）
      ├─ LiveGridScreen        Compose 响应式网格
      ├─ LivePlayerScreen      Compose + PlayerView + ExoPlayer(HLS)
      ├─ SearchOverlay         Compose 搜索框、结果网格与分页
      ├─ LoginScreen           WebView，仅处理扫码授权
      └─ AccountOverlay        登录状态与退出入口
```

## 页面状态与返回键

`DouyinTvApp` 是顶层状态机。Back 的优先级固定为：

1. 关闭登录页。
2. 关闭搜索层。
3. 关闭账号浮层。
4. 关闭直播间。
5. 关闭博主主页。
6. 关闭推荐页评论面板，保留顶栏并恢复“评论”按钮焦点。
7. 收起推荐页顶栏。
8. 从侧边栏播放视频且存在返回快照时，恢复对应的“我的主页”或博主主页侧边栏，
   切回原标签页，并自动滚回、聚焦刚播放的视频或合集卡片。
9. 返回快照已消费后，从侧边栏来源播放的视频页按 Back 恢复进入侧边栏前的推荐流。
10. 在根页面退出应用。

直播间关闭时，ViewModel 记录房间 ID，并在网格重新挂载后恢复焦点，而不是保存
旧的可组合对象或索引。

## 短视频链路

1. ViewModel 拉取推荐页并预取接近列表尾部的下一页。
2. `ShortsPlaybackEngine` 将当前推荐流维护为同一条 ExoPlayer 播放队列，上下切换只
   移动队列索引；分页追加时扩展队列，列表被替换时重建。当前地址失败时替换该队列项
   并尝试下一个候选地址。需要登录态的抖音取流入口只在抖音域内重定向时携带当前会话
   Cookie；解析到独立媒体 CDN 后改用无 Cookie 的直链播放，避免把会话凭据带到第三方
   媒体主机。
3. 短视频媒体通过 128 MiB LRU 短期缓存读取。当前视频进入可播放状态后，Media3
   `DefaultPreloadManager` 按距离分级预热前 1 条和后续视频：标准档后续 4 条，低端档
   后续 2 条；相邻视频优先预热开头 8 秒，切回前一条时可优先从本地缓存读取。
4. 主播放器使用全屏固定尺寸的 `SurfaceView` 和 `RESIZE_MODE_FIT` 保持原始宽高比，
   保留硬件叠加层直通路径，避免 TextureView 每帧额外 GPU 合成造成掉帧。切换不替换
   `MediaSource` 或 Surface，播放队列保留上一帧直到新视频首帧就绪，因此不会露出黑色
   Surface；连续快速切换只提交最后一次准备请求，避免反复重建硬件解码器。
5. 播放器错误会显示可聚焦的重试面板；视频结束自动切下一条。
6. 生命周期进入后台时暂停，恢复前台时仅在没有用户暂停意图时继续播放。
7. 切换到新视频时并行加载评论和官方弹幕；评论只在该视频的详情面板中展示。
8. 打开评论面板不改变暂停意图，面板覆盖右侧 1/3 并隐藏控制层；关闭后恢复视频
   焦点并重新显示顶栏，再次按 Back 才收起顶栏。
9. 打开收藏夹、我的主页或博主主页不改变播放器的暂停意图；侧栏打开期间视频在左侧
   2/3 继续播放，关闭后恢复全区域播放并重新把焦点交给视频。
10. 播放器按设备档位每 3 或 5 秒把位置和总时长写入本机进度库，列表项重进收藏、
    我的主页或博主主页时读取展示。
11. 离开短视频页时先清空预热窗口并释放预载管理器，最后释放播放器，避免预热回调
    访问已释放的选轨器。

## 评论与弹幕链路

1. 评论通过公开移动网页评论接口读取，使用遥控器进入右侧面板；最多展示约 10 条
   热门评论，包括正文、作者、IP 属地、点赞数和回复数。
2. 评论列表的每一行都是稳定焦点目标，上下键逐条移动并自动滚入可视区；Back 或
   右上角关闭按钮退出面板。
3. 官方弹幕通过桌面网页接口分页请求，按播放器 `currentPosition` 投影到五条轨道；
   没有官方时间轴弹幕的视频保持空白，不使用评论补位。
4. 每条轨道同一时刻只绘制一条消息，使用大字号、中速、无底色文字，消息完整滚出
   左侧后才复用轨道；轨道仍被占用时跳过冲突的新消息，不覆盖正在滚动的弹幕。
5. 弹幕区固定为屏幕最顶部约 22% 高度并收紧行距。评论面板打开时整体隐藏；打开
   我的主页或博主侧栏时继续滚动，只覆盖左侧视频区域。

## 直播链路

1. 直播广场加载房间卡片。
2. 屏幕宽度小于 `800.dp` 使用三列，否则使用四列。
3. 打开房间后解析 HLS/FLV 地址，优先使用 HTTPS HLS。
4. 直播画面使用 `RESIZE_MODE_FIT`，竖屏直播保留黑边而不拉伸。
5. 返回网格后按业务房间 ID 恢复焦点。

## 我的主页与博主主页链路

1. 登录后启动推荐流时并行加载收藏列表，收藏状态用于顶栏的“收藏/取消收藏”。
2. 收藏动作通过网页接口提交；成功后同步更新本地状态，失败保留原状态并显示错误。
3. 账号头像打开“我的主页”侧边栏，包含观看历史、我的收藏和我的主页三个标签；
   观看历史与收藏列表显示标题、封面、时长和最后播放进度。
4. “我的主页”标签使用当前登录账号的 `sec_uid` 调用本人作品接口，分页加载本人
   发布视频，列表显示封面、标题、时长和点赞；选择后替换主播放器队列并播放。
5. 博主主页使用同一个右侧侧边栏框架，按当前视频的 `sec_uid` 分页加载公开视频；
   选择列表项后替换主短视频队列的当前来源并播放。
6. 打开博主主页时同步加载公开合集。“合集”使用作者 `sec_uid` 调用合集列表接口，
   卡片展示封面、名称、集数、播放量；选中后按 `mix_id` 拉取合集视频并在主播放器播放。
   作者没有公开合集时不显示空白合集页签，加载失败时保留页签和重试入口。
7. 博主主页只提供视频和合集页签，不展示“喜欢”页签。
8. 两类侧边栏固定占屏幕右侧 1/3，打开时不暂停视频；视频和弹幕限制在左侧 2/3
   区域继续显示。顶部资料区使用紧凑字号与间距，低端档位关闭阴影、反射层和焦点缩放。
9. 侧边栏页签使用显式向下焦点链进入首个列表项；列表内上下键按网格逐行移动，只有
   首行再向上才返回当前页签。从侧边栏选择视频后保存来源侧栏、标签页和视频/合集 ID。
   首次按 Back 恢复对应侧边栏，并自动滚回、聚焦刚播放的卡片；再次按 Back 关闭侧边栏，
   之后才返回到进入侧栏前的推荐流。打开侧边栏时自动定位到当前播放卡片，并在该卡片
   上压暗显示居中的“播放中”小字。关闭博主主页时保留视频操作区，并把焦点恢复到
   “主页”按钮；关闭评论面板时回到“评论”按钮。再次按 Back 先收起视频操作区，之后
   才进入首页返回流程。播放进度只保存在应用私有 SharedPreferences，不上传，也不会
   自动定位到上次位置。
10. 从侧边栏来源播放视频时，顶栏只保留搜索和账号入口，隐藏“推荐 / 直播”主导航；
    从推荐、搜索等非侧栏来源播放时保持完整顶栏。

## 搜索链路

1. 推荐页和直播页顶栏的搜索按钮打开 Compose 搜索层，并聚焦 `BasicTextField`；
   TV 端通过系统软键盘输入，Back 只先收起键盘。
2. 提交后请求桌面网页搜索接口，结果复用短视频模型、封面和播放队列；列表支持分页、
   重试和替换主播放器来源。
3. 抖音当前对第三方搜索请求返回 HTTP 成功但 `search_nil_info.search_nil_type` 为
   `verify_check`。客户端识别该字段并显示平台安全校验提示，不把拦截误判为无结果。
4. 搜索不通过 WebView 或网页套壳绕过校验。

## 语音命令链路

1. 方舟/全局语音助手先打开 `.voice.VoiceEntryActivity`，再由
   `content://com.dongpiandi.douyintv.voice.commands` 调用 `dispatch`。
2. `VoiceCommandProvider` 用 `Binder.getCallingUid()` 对应的包名做白名单校验，只接受
   `com.dongpiandi.voicehelper`（或抖音自身）。命令随后进入带时间戳的进程内队列。
3. 抖音已在前台时只提交队列，不启动新 Activity；后台时由入口页拉起主界面，主界面
   在 `STARTED` 生命周期消费队列。超过 30 秒的队列项丢弃。
4. 搜索命令与界面手动搜索共用 `MainViewModel.submitSearch()`。`openFirstResult=true`
   时只在搜索结果成功、非安全校验且首条存在时调用 `playSearchResult()`；否则保留
   搜索页或校验提示。
5. 暂停、继续、上一条、下一条、评论、收藏和作者主页直接调用 `MainViewModel` 的既有
   状态方法，不使用延迟 D-pad 或无障碍点击。

## 登录与会话

- 登录地址为 `https://www.douyin.com/user/self`，使用桌面 UA。
- 页面加载后尝试展开官方扫码登录弹层，并周期性校正弹层位置与尺寸。
- 检测到包含 `sessionid` 或 `sessionid_ss` 的 Cookie 后，关闭 WebView 并保存会话。
- Cookie 使用 Android Keystore 中的 AES-GCM 密钥加密，存放在应用私有
  SharedPreferences。
- 退出登录会删除密文和 Keystore 密钥，并清除 WebView Cookie。

这里没有账号密码代填，也没有自建认证服务器。WebView 的权限和能力只服务于
抖音官方登录页。

## 响应式布局

界面以电视横屏为基准：

- 登录页使用左右两栏，二维码 WebView 弹层在可用区域内垂直居中。
- 短视频底部信息面板最大 `280.dp`，且不超过屏幕宽度的 28%，不再放置遥控操作提示。
- 弹幕区从屏幕最顶部开始，固定占用约 22% 高度，五行行距收紧；评论面板打开时隐藏，
  我的主页或博主侧栏打开时继续滚动并限制在左侧视频区。弹幕只使用带原始时间偏移的
  官方数据，严格按播放进度显示；没有弹幕的时间段保持空白，不循环或用评论补位。
- 推荐页顶栏使用独立玻璃胶囊按钮，不再绘制整条深色背景；推荐、直播、评论、收藏、
  收藏夹、博主和账号通过显式方向焦点链连接，避免方向键把焦点带出顶栏或落到播放器；
  顶栏获得焦点期间不会因 4 秒空闲自动收起。侧边栏视频成为当前播放来源时，顶栏
  隐藏推荐/直播主导航，只保留搜索和账号；返回对应侧边栏或推荐流后恢复完整导航。
- 评论面板固定占屏幕右侧 1/3，视频区域固定保留左侧 2/3；评论字号与头像同步缩小
  以适配窄面板。
- “我的主页”和博主主页沿用右侧 1/3 侧边栏，顶部标题、头像、资料、标签与列表项
  使用紧凑字号；低端设备不绘制阴影和多层反射，避免侧边栏展开时额外抖动。侧边栏
  打开后焦点限制在面板内部，底层菜单和视频操作区不再参与方向导航；博主主页通过
  返回键关闭后回到“主页”按钮，评论面板关闭后回到“评论”按钮。
- 直播网格按 `800.dp` 阈值切换三/四列。
- 所有主要操作均有可见焦点环；顶部导航、信息面板、侧边栏列表和错误面板可按
  D-pad 到达。

## 失败与限制

- 官方接口或签名变化可能导致推荐/直播请求失败。
- 评论接口的可用字段和数量由公开移动网页接口决定，可能少于网页端完整评论区。
- 没有官方时间轴弹幕的视频不生成替代弹幕，对应时间段保持空白。
- 收藏夹、收藏动作、搜索、合集和博主视频依赖登录会话及网页风控，接口变化后可能
  返回 403、空列表或 `verify_check`。
- 第三方搜索目前被抖音安全校验拦截；客户端保留完整入口和错误识别，但不能保证
  返回结果。
- 博主主页不提供“喜欢”页签；没有公开合集的作者只显示视频页签。
- 播放进度仅用于展示，不会自动续播；记录只在本机保留，最多 400 条。
- 登录页 DOM 变化可能导致二维码弹层探测失败。
- 媒体 CDN 可能校验 Referer、Cookie 或短期签名，旧播放地址会失效。
- 当前只有短视频短期媒体缓存和内存预载，不提供离线下载管理、自动更新、崩溃上报
  或远程配置。
- `0.2.0` 起支持 Release 构建，签名材料在仓库外注入，仓库不保存密钥库。
