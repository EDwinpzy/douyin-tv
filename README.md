# Douyin TV（非官方）

面向 Android TV 与投影设备的第三方抖音客户端，使用 Kotlin、Jetpack Compose
和 AndroidX Media3 原生实现。应用只保留两条主路径：遥控器刷推荐短视频和观看
直播，并支持评论、弹幕、收藏、搜索、查看博主/本人主页以及使用抖音 App 扫码登录
自己的账号。

> 本项目与抖音/字节跳动没有关系，不提供或重新分发抖音内容。请阅读
> [免责声明](DISCLAIMER.md) 后再使用。

## 功能

- 推荐短视频：上下切换、暂停/继续、前后快进、自动连播和失败重试；当前视频就绪后
  按设备档位分级预热后续 2–4 条。播放中控制层 4 秒无操作自动隐藏，暂停时保持
  显示；Menu 或第一条视频再按上可唤出顶栏。切换视频时不显示封面占位，新视频首帧
  就绪后直接显示，并用视频宽高固定播放框，避免首帧或尺寸突然变化。
- 弹幕：显示视频的官方时间轴弹幕。固定三条无底色轨道，大字慢速从右侧完整滚出左侧
  后才复用轨道；轨道仍被占用时跳过冲突消息，不覆盖正在滚动的弹幕。打开我的主页或
  博主侧栏时弹幕继续滚动并只覆盖左侧视频区域，评论面板打开时暂时隐藏。
- 评论：视频信息面板进入右侧评论面板，显示评论总数、头像、昵称、正文、IP 属地、点赞和
  回复数；面板固定占屏幕右侧 1/3，视频保留左侧 2/3；打开评论不会暂停视频，Back
  仅关闭评论并保留顶栏和当前播放状态。
- 收藏：登录后可在视频信息面板收藏或取消收藏当前视频；收藏夹按账号分页加载收藏视频，列表
  项显示封面、标题、时长和本机记录的最后播放进度。
- 博主主页：从视频信息面板进入当前视频作者的主页，分页浏览公开视频和合集；没有公开
  合集的作者不显示空白合集页签，也不再提供喜欢页签。合集可继续加载并播放其中的视频。
  选择列表项后直接在播放器中播放，并沿用播放下一条、快进快退和评论等能力。
- 本机主页：账号头像打开右侧“我的主页”，可查看观看历史、我的收藏，并在“我的主页”
  标签中分页浏览本人发布的视频；列表显示封面、标题、时长、点赞和本机播放进度，
  选择后直接在主播放器播放。本人作品播放使用当前登录会话取流。侧边栏使用紧凑
  排版和玻璃材质，低端设备自动关闭阴影及缩放动效。
- 播放进度：播放中按设备档位每 3–5 秒把当前视频的进度保存到本机，供收藏夹、
  我的主页和博主主页显示；退出应用或切换账号不会上传这些进度。
- 直播广场：响应式三列/四列网格，按 OK 进入直播间，返回后恢复原卡片焦点。
- 直播播放：支持 HLS/FLV 地址，竖屏直播保持原始比例并显示黑边，不拉伸。
- 账号登录：WebView 仅承载抖音官方扫码登录页，成功后使用自己的会话获取推荐。
- 账号菜单：显示登录状态并支持退出登录。
- 搜索：推荐页和直播页顶栏均可打开搜索层，使用 TV 系统软键盘输入关键词，结果支持
  分页和直接播放。抖音当前对第三方搜索请求返回 `verify_check` 安全校验时，界面会
  明确显示平台限制，不会把拦截误报成“没有找到视频”。
- TV 交互：全局 D-pad 焦点、分层 Back、全屏横屏和播放时保持亮屏。

短视频和直播均由原生 ExoPlayer 播放，不存在把完整抖音网页放进 WebView 的套壳
界面。

## 环境与构建

要求：

- Windows PowerShell
- JDK 17
- Android SDK Platform 35
- Android TV / 投影设备或模拟器，Android 8.0（API 26）及以上

构建和检查：

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:testDebugUnitTest
.\gradlew.bat :app:lintDebug
```

Debug APK 位于 `app\build\outputs\apk\debug\app-debug.apk`。安装并启动：

```powershell
adb install -r .\app\build\outputs\apk\debug\app-debug.apk
adb shell am start -n com.dongpiandi.douyintv/.MainActivity
```

## 发布

Release 构建使用仓库外的专用签名材料，签名文件和密钥库都不入库：

```powershell
$env:DOUYINTV_KEYSTORE_PROPERTIES = "$env:USERPROFILE\.android\douyintv-release\keystore.properties"
.\gradlew.bat :app:assembleRelease :app:bundleRelease
```

`keystore.properties` 需要包含 `storeFile`、`storePassword`、`keyAlias`、`keyPassword`
四项；构建脚本也会依次读取仓库根目录的 `keystore.properties` 和 `local.properties`。
缺少这些文件时 release 构建会退回 debug 签名，因此正式发布前必须用
`apksigner verify --print-certs` 确认签名证书。

产物：

- `app\build\outputs\apk\release\app-release.apk`：直接安装的 APK。
- `app\build\outputs\bundle\release\app-release.aab`：应用商店上传包。

Release 包与 Debug 包签名不同，无法直接覆盖安装；升级需先卸载旧版，登录会话
需要重新扫码获取。

## 原生边界

- **界面**：Jetpack Compose，按电视横屏设计，无手机触摸布局。
- **短视频/直播播放**：Media3 ExoPlayer，使用 HTTPS 媒体地址。
- **登录**：WebView 加载官方 `https://www.douyin.com/user/self` 页面，桌面 UA；
  检测到有效会话 Cookie 后关闭。
- **数据**：不包含自建后端，不上传会话；请求直接发往抖音相关服务。
- **会话**：Cookie 由 Android Keystore 中的 AES-GCM 密钥加密后保存在本机。
- **取流**：仅在抖音域内按取流重定向携带会话，跨到独立 CDN 域名后不再附带 Cookie。

项目没有内置抖音 APK、反编译产物、抓包数据、账号 Cookie 或签名材料。媒体地址
和请求参数可能随抖音服务变化，详见 [架构说明](docs/architecture.md)。

## 已知限制

- 依赖抖音网页接口和签名逻辑，服务端调整后可能需要更新代码。
- 二维码依赖官方登录页 DOM；页面结构变化可能影响自动展开和定位。
- 评论为只读，当前只请求公开移动网页接口返回的一页热门评论，不包含二级回复
  分页；不支持在电视上写评论、点赞或回复。
- 弹幕为只读；没有官方时间轴弹幕的视频保持空白，不使用热门评论补位，也不支持发送弹幕。
- 收藏、搜索和博主主页依赖登录会话及网页接口；接口、隐私设置或风控变化时可能
  返回空列表或校验提示。
- 播放进度只保存在本机并用于展示，不会自动从上次位置续播；清除应用数据后会丢失。
- 搜索入口已接入，但抖音在 2026 年对第三方网页搜索统一返回 `verify_check`；
  当前只能显示平台限制提示，不能绕过安全校验返回搜索结果。
- 当前不包含点赞、关注、发布、私信或直播间聊天功能。
- 没有自动化 TV UI 测试，也没有跨厂商设备矩阵。
